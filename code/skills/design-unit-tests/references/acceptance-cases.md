# 行为验收场景

| 场景 | 应有行为 |
| --- | --- |
| 设计是从存在已知错误的代码还原的 | 将历史行为测试标为 CHARACTERIZATION，不把错误输出当符合性标准 |
| 设计规定边界条件，但没有说明等于阈值时的行为 | 标记对应用例阻断并澄清，不擅选大于或大于等于 |
| 被测单元依赖时钟 | 明确真实单元和假时钟行为，区分逻辑时间与实际实时性 |
| 调用方保证输入非空，单元未承诺防御空值 | 不将任意空值处置强加为符合性要求 |
| 输出为浮点数，资料没有误差规定 | 请求依据或提出待确认比较方案，不默认 1e-6 为批准容差 |
| 尚未执行任何测试 | 只输出计划覆盖，不宣称覆盖率达标或测试通过 |
