# 行为验收场景

| 场景 | 应有行为 |
| --- | --- |
| 框架绿色，但用例未被发现或断言被禁用 | 不认可有效通过，说明执行或证据问题 |
| 实现输出与从同一实现复制的预期一致 | 限定为行为基准一致，不宣称正确性 |
| 第一次失败，第三次通过 | 保留所有 RUN，分析不稳定性，不覆盖首次失败 |
| 桩返回值违反接口契约 | 调查替身和用例，不立即认定实现错误 |
| 有效测试输入触发实现崩溃 | 保留有效失败可能性，不自动归类基础设施无效 |
| 只提供 100% 覆盖率截图 | 说明基线、断言和原始结果不足，不能判整体通过 |
| 缺少执行数据 | 请求证据，不生成虚构测试结果 |
