## 1. 结论边界

记录评估标识、日期、单元与配置范围、用例集和代码基线、设计依据。

分别给出有效性、测试义务满足情况、覆盖缺口及稳定性结论；总述为“证据支持已审义务满足／存在不满足证据／证据不足”。允许不同单元具有不同结论，不用一个百分数抹平差异。

执行状态为 VALID／INVALID／BLOCKED／NOT_RUN／UNKNOWN；评估断言结果为 PASS／FAIL／INCONCLUSIVE／NOT_EVALUATED。无效执行不能计入有效通过或有效失败。

## 5. 问题记录

每项记录问题编号、首次偏离、预期与实际、证据位置、影响、候选根因、支持和反对证据、确定性、建议负责人、区分试验和回归范围。

明确区分观察到失败与确认实现错误。记录设计、测试和实现可能共享同一错误的限制。
