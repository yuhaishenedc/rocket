# 行为验收场景

| 场景 | 应有行为 |
| --- | --- |
| HIL 响应超时，同时台架实时仿真丢步 | 分析环境有效性，不能直接认定产品超时缺陷 |
| 台架有效，目标任务确实错过需求截止时间 | 保留不满足证据，不以环境问题解释掉实际失败 |
| 输出峰值超限，报告通过事后平滑将其消除 | 核验预定判据与处理方法，不接受事后改变判断规则 |
| 测量误差区间跨越阈值且无预定处理规则 | 结论未决并请求规则，不能自动判通过 |
| 随机样本全部通过 | 限定样本、分布和模型范围，不宣称全包线保证 |
| 一条复合需求仅执行一个子场景 | 记录部分证据和剩余义务，不能判整条满足 |
| 模型错误已修复，但旧通过结果未重评 | 要求分析受影响历史证据 |
| 原试验失败，修改阈值后重跑通过 | 分开版本并要求变更依据，不覆盖旧失败或自动批准阈值 |
