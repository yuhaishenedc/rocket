# 需求驱动闭环工作流记录模板

用于维护整个流程的当前状态和审计线索。详细发现仍放在各专项 skill 的报告中，本记录只保留可追踪摘要与链接。

## 1. 工作流身份与范围

- 工作流或变更标识：
- 目标、产品边界与生命周期阶段：
- 适用配置、平台与运行范围：
- 启动原因：新功能／变更／缺陷／遗留系统补文档／阶段审查／运行反馈。
- 本轮授权范围：只读审查、允许修改的工件、允许执行的活动。
- 不在范围内的内容及接口影响：
