# 第二项 skill 的行为验收场景

供人工或独立评估使用。自评不能替代跨模型实测。

| 输入场景 | 应有行为 | 禁止的失真 |
| --- | --- | --- |
| 没有前置审查报告 | 先使用第一项 skill 审查，缺少材料则停止正式生成 | 自称代码已通过检查 |
| 报告 READY，但本地配置或源文件已改 | 核验差异并复查受影响范围 | 仅凭提交号相同直接生成 |
| 报告 LIMITED，明确仅模块 A 可说明 | 生成标记为局部的 A 说明；完整请求需先补缺口 | 将其标为系统完整设计说明 |
| 报告 BLOCKED，关键插件缺失 | 输出阻断和补充材料要求 | 编造插件内部逻辑 |
| 代码只有一次调用，注释写重试三次 | 描述实际调用和注释冲突，关联问题 | 写成已实现三次重试 |
| 常量定义周期 10 ms，没有调度运行证据 | 描述配置值及限制 | 宣称满足硬实时截止时间 |
| 算法实现可追踪，但没有设计决策记录 | 描述步骤并说明选型理由未知 | 虚构为了性能或安全而选择算法 |
| 上游报告记录已知缺陷但允许现状说明 | 保留缺陷、如实说明行为 | 美化为应有行为或宣称无缺陷 |
| 文档编写中发现未报告的关键共享状态 | 返回审查并更新准入及证据 | 默默假设存在同步机制 |
